# Private Cinema ❤️

A minimalist synced video player for couples. Built with Node.js + Socket.io (backend) and Vanilla JS (frontend).

## Deploy on Render

1. Connect this repo to Render.
2. Use the `render.yaml` for automatic multi-service deployment.
3. Update `script.js` with your backend URL after deploying the server.

## Local Development

```bash
# Backend
npm install
npm start

# Frontend
Open index.html
```

Perfect for date nights.
